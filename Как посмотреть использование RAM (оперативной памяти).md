Посмотреть использование оперативной памяти (RAM) и файла подкачки (Swap) в Linux можно как одной быстрой командой, так и с помощью интерактивных утилит.

Вот основные способы, от простых к глубоким.

## 1. Команда `free` — Быстро и классически

Это самый популярный способ мгновенно узнать состояние памяти. Она установлена везде по умолчанию.

Всегда запускайте её с флагом **`-h`** (human-readable), чтобы увидеть значения в мегабайтах и гигабайтах, а не в байтах.

Bash

``` Bash
free -h
```

**Пример вывода:**

``` 
	 total       used        free      shared  buff/cache   available
Mem: 15Gi        8.2Gi       1.1Gi     1.2Gi   6.1Gi        6.2Gi
Swap:2.0Gi       512Mi       1.5Gi
```
### Как правильно читать этот вывод:

- **total** — сколько всего RAM установлено в системе.
- **used** — сколько памяти **реально занято** вашими программами прямо сейчас.
- **free** — абсолютно чистая, никем не занятая память. _В Linux это число почти всегда маленькое, и это нормально!_
- **buff/cache** — память, которую Linux временно забрал под кэш диска, чтобы система работала быстрее. Если программам понадобится память, ОС мгновенно отдаст её из этого кэша.
- **available** — **самый важный показатель**. Он показывает, сколько памяти приложения могут занять _на самом деле_ (с учетом очистки кэшей). Ориентируйтесь именно на него.
- **Swap** — использование файла или раздела подкачки на диске. Если `used` в строке Swap быстро растет — физической памяти не хватает и система начинает сильно тормозить.

## 2. Интерактивный мониторинг (`htop` и `top`)

Если вам нужно видеть, как память заполняется в динамике и кто её «ест».

- **`htop`** — вверху экрана вы увидите строку **`Mem`**. У `htop` отличная цветовая кодировка полосы памяти:
    - **Зеленый** — память, занятая процессами (реально использованная).
    - **Синий** — буферы.
    - **Желтый/Оранжевый** — кэш.
- **`top`** — данные о памяти находятся в шапке, в строках `MiB Mem` и `MiB Swap`. Чтобы отсортировать список процессов по потреблению памяти, нажмите заглавную букву **`M`**.

## 3. Файл `/proc/meminfo` — Вся подноготная

Если вам нужны не просто общие цифры, а детальная статистика (например, сколько памяти уходит на таблицы страниц ядра или Shared memory), можно заглянуть напрямую в виртуальную файловую систему Linux.

```Bash
cat /proc/meminfo
```

Вывод будет огромным (около 50 строк). Чтобы вытащить оттуда только главное, можно использовать фильтр:

```Bash
egrep --color 'MemTotal|MemFree|MemAvailable|Cached|SwapTotal|SwapFree' /proc/meminfo
```

## 4. Как найти самые прожорливые процессы?

Если памяти осталось мало и нужно срочно найти виновника, выполните эту команду. Она выведет топ-5 процессов, отсортированных по потреблению RAM:

``` Bash
ps -eo pid,ppid,cmd,%mem --sort=-%mem | head -n 6
```

### Шпаргалка: что использовать?

- Нужно быстро узнать «свободно/занято»? Пишите **`free -h`**.
- Нужно закрыть зависшую программу, которая сожрала память? Запускайте **`htop`** (сортировка по памяти там включена по клику на колонку `MEM%`).
- Пишете скрипт автоматизации? Используйте **`free -h`** или парсите **`/proc/meminfo`**.
