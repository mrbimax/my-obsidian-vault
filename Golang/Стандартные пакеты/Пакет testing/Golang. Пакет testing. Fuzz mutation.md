# Golang. Пакет testing. Fuzz mutation

## Назначение

Fuzz mutation — процесс изменения существующих входных данных для создания новых тестовых случаев.

Go fuzzing не генерирует полностью случайные данные с нуля, а в основном:

```text
seed input
      |
      ↓
mutation
      |
      ↓
new input
```

---

## Пример

Seed:

```go
f.Add("hello")
```

Fuzzer может создать:

```text
hello
helo
Hello
hello!
hello000
hello\x00
```

---

## Основные виды мутаций

### 1. Замена значений

Было:

```text
hello
```

Стало:

```text
hallo
```

или:

```text
Hello
```

Используется для поиска:

- ошибок сравнения;
    
- неправильной обработки символов.
    

---

### 2. Удаление данных

Было:

```text
hello world
```

Стало:

```text
hello
```

или:

```text
hell
```

Помогает найти проблемы:

- пустые значения;
    
- короткие строки;
    
- выход за границы.
    

---

### 3. Добавление данных

Было:

```text
user
```

Стало:

```text
user123
```

или:

```text
userAAAAAAAA
```

Используется для поиска:

- переполнений;
    
- проблем с длиной;
    
- ошибок парсинга.
    

---

### 4. Изменение байтов

Для:

```go
[]byte
```

пример:

Было:

```text
48 65 6c 6c 6f
```

Стало:

```text
48 FF 6c 6c 6f
```

Часто используется для:

- бинарных форматов;
    
- протоколов;
    
- декодеров.
    

---

### 5. Изменение чисел

Seed:

```go
f.Add(100)
```

Возможные значения:

```text
0
1
99
101
-1
MaxInt
MinInt
```

Особенно важны границы типов:

```text
int8:

127
128
-128
-129
```

---

## Coverage-guided mutation

Главная особенность Go fuzzing:

мутация оценивается не только по результату, а по **coverage**.

Схема:

```text
input
  |
  ↓
mutation
  |
  ↓
run program
  |
  ↓
new code path?
  |
  ├── да → сохранить input
  |
  └── нет → отбросить
```

---

## Пример

Код:

```go
func Parse(s string) {

	if len(s) > 0 && s[0] == 'A' {

		if s == "ADMIN" {
			panic("bug")
		}

	}

}
```

Fuzzer может двигаться:

```text
hello
 ↓
Apple
 ↓
ADMIN
```

Потому что каждый шаг открывает новую ветку:

```go
s[0] == 'A'
```

затем:

```go
s == "ADMIN"
```

---

## Mutation и JSON

Важно:

Go не знает:

```json
{
 "age": 20
}
```

Он видит:

```text
7b 22 61 67 65 22 3a 32 30
```

Мутация происходит над байтами.

Если случайно получилось:

```json
{
 "age": 21
}
```

это просто удачная мутация.

---

## Corpus и mutation

Corpus:

```text
testdata/
└── fuzz/
    └── FuzzParser/
        └── valid.json
```

Fuzzer:

```text
valid.json
      |
      ↓
mutation
      |
      ↓
broken.json
```

Новый интересный случай добавляется обратно в corpus.

---

## Минимизация

Если найден большой вход:

```text
AAAAAAAAAAAAAAAAADMINBBBBBBBB
```

Fuzzer пытается уменьшить:

```text
ADMIN
```

Чтобы ошибка воспроизводилась проще.

---

## Для собеседования

> Fuzz mutation — это изменение существующих seed inputs для поиска новых случаев. Go fuzzing использует coverage-guided подход: сохраняет только те мутации, которые открывают новые пути выполнения. Мутации могут изменять байты, удалять, добавлять данные или менять значения. Fuzzer работает на уровне данных, а не понимает бизнес-структуру вроде JSON.
