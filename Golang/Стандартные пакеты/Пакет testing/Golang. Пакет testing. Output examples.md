# Golang. Пакет testing. Output examples

## Назначение

`// Output:` — специальный комментарий в Example-функциях, который задаёт **ожидаемый вывод программы**.

Если фактический вывод отличается, Example считается неуспешным.

---

## Синтаксис

```go
func ExampleAdd() {

	fmt.Println(Add(2, 3))

	// Output:
	// 5
}
```

Go:

1. запускает Example;
    
2. перехватывает `stdout`;
    
3. сравнивает вывод с `Output`.
    

---

## Несколько строк

```go
func ExampleGreeting() {

	fmt.Println("Hello")
	fmt.Println("World")

	// Output:
	// Hello
	// World
}
```

Порядок и содержимое строк должны полностью совпадать.

---

## Если вывод отличается

```go
func ExampleAdd() {

	fmt.Println(Add(2, 3))

	// Output:
	// 6
}
```

Результат:

```text
got:
5

want:
6
```

Example завершится с ошибкой.

---

## Example без Output

```go
func ExampleServer() {

	server := NewServer()
	server.Start()
}
```

Такой Example:

- выполняется;
    
- проверяет отсутствие `panic`;
    
- не сравнивает вывод.
    

---

## Что сравнивается

Сравнивается только вывод в `stdout`.

Например:

```go
fmt.Println("Hello")
```

учитывается, а:

```go
log.Println("Hello")
```

не рекомендуется использовать в Example, так как логгер может добавлять дату, время и другую информацию, делая вывод недетерминированным.

---

## Ограничения

Output должен быть:

- детерминированным;
    
- одинаковым при каждом запуске.
    

Плохо:

```go
fmt.Println(time.Now())
```

или

```go
fmt.Println(rand.Int())
```

---

## Для собеседования

> `// Output:` — специальный комментарий в Example-тестах. После выполнения функции Go сравнивает содержимое `stdout` с указанным выводом. Если они не совпадают, Example считается неуспешным. Это позволяет одновременно документировать API и автоматически проверять актуальность примеров.
