# Шпаргалка: `chown` (Change Owner)

**`chown`** — утилита в Linux, предназначенная для изменения **владельца** (owner) и/или **группы** (group) файлов и директорий. Управление владельцами критически важно для безопасности и правильной работы демонов (например, чтобы Nginx или Docker имели доступ к своим каталогам).

> ⚠️ **Важно:** Менять владельца файлов обычно может только суперпользователь (`root`), поэтому команда практически всегда используется через `sudo`.

## 🚀 Базовый синтаксис

Bash

``` Bash
chown [опции] [новый_владелец][:новая_группа] /путь/к/файлу
```

_Вместо двоеточия (`:`) можно использовать точку (`.`), но двоеточие является современным стандартом._

## 💡 Практические кейсы использования

### 1. Изменение только владельца

Полезно, если файл был создан из-под `root`, но его нужно отдать конкретному пользователю.

Bash

``` Bash
sudo chown magnum_opus main.go
```

### 2. Изменение только группы

Если нужно сменить группу, оставив текущего владельца на месте (перед именем группы обязательно ставится `:`).

Bash

``` Bash
sudo chown :www-data config.yaml
```

### 3. Изменение владельца и группы одновременно (Частый кейс)

При разворачивании приложения отдаем права на всю папку конкретному юзеру и группе веб-сервера.

Bash
```Bash
sudo chown magnum_opus:www-data /var/www/my-app
```

### 4. Рекурсивное изменение (Для папок)

Флаг **`-R`** (Recursive) применяет изменения к указанной папке, а также ко всем вложенным файлам и подкаталогам.

Bash
```Bash
sudo chown -R magnum_opus:www-data /var/www/my-app
```

## 🛠️ Полезные фичи и трюки

- **Автоматически выставить группу, совпадающую с юзером:** Если указать имя пользователя и поставить двоеточие, но _оставить поле группы пустым_, Linux автоматически назначит файлу основную (login) группу этого пользователя.
    Bash
    ```Bash
    sudo chown magnum_opus: main.go
    # Выставит владельца magnum_opus и его дефолтную группу
    ```
- **Скопировать владельца с другого файла (Reference):** Чтобы не прописывать руками, можно сказать: «Сделай у `file2.txt` таких же хозяев, как у `file1.txt`».
    Bash
    ```Bash
    sudo chown --reference=file1.txt file2.txt
    ```
