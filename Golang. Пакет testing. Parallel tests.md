# Golang. Пакет testing. Parallel tests

## Назначение

Параллельные тесты позволяют выполнять независимые тесты одновременно.

Для этого используется:

```go
t.Parallel()
```

Это сокращает общее время выполнения тестов.

---
## Синтаксис

```go
t.Parallel()
```

---
## Простой пример

```go
package main

import (
	"testing"
	"time"
)

func TestA(t *testing.T) {
	t.Parallel()

	time.Sleep(time.Second)
}

func TestB(t *testing.T) {
	t.Parallel()

	time.Sleep(time.Second)
}
```

Оба теста будут выполняться одновременно.

---
## Параллельные subtests

```go
package main

import "testing"

func TestUsers(t *testing.T) {

	tests := []string{
		"create",
		"delete",
		"update",
	}

	for _, name := range tests {

		name := name

		t.Run(name, func(t *testing.T) {

			t.Parallel()

			// тест

		})
	}
}
```

---
## Когда начинается выполнение

```go
func TestA(t *testing.T) {
	t.Parallel()

	// ...
}
```

После вызова `t.Parallel()` тест **приостанавливается**.

Он продолжит выполнение только после того, как родительский тест (или функция верхнего уровня) завершит свою подготовку.

---
## Порядок выполнения

```text
TestA
  │
  ├── setup
  │
  ├── t.Parallel()
  │
  └── ожидание

TestB
  │
  ├── setup
  │
  ├── t.Parallel()
  │
  └── ожидание

---------------------

A и B выполняются одновременно
```

---
## Ограничение количества потоков

Максимальное число одновременно выполняемых тестов задаётся флагом:

```bash
go test -parallel=8
```

По умолчанию используется значение `GOMAXPROCS`.

---
## Когда использовать

Подходит для:

- независимых unit-тестов;    
- вычислений;    
- парсеров;    
- сериализации;    
- чистых функций.    

Не подходит для:

- тестов с общей БД;    
- общего файла;    
- глобальных переменных;    
- общего состояния без синхронизации.    

---
## Важный нюанс

При использовании цикла необходимо копировать переменную:

```go
for _, tt := range tests {
	tt := tt
	t.Run(tt.name, func(t *testing.T) {
		t.Parallel()
		// использование tt
	})
}
```

Это предотвращает проблемы с захватом переменной цикла (особенно в старых версиях Go).

---
## Для собеседования

> `t.Parallel()` помечает тест как параллельный. После вызова тест приостанавливается и продолжает выполнение одновременно с другими параллельными тестами. Используется только для независимых тестов без общего изменяемого состояния.
