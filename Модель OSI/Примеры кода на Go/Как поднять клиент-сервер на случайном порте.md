Данный пример на [[Go]] видоизменяет этот пример: [[TCP клиент-сервер на Go]].
### 1. Измененный [[TCP]]-Сервер (порт `:0`)

Go

``` run-go
package main

import (
	"fmt"
	"net"
	"os"
)

func main() {
	// Указываем порт :0 — это сигнал для ОС выбрать случайный свободный порт
	listener, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		fmt.Println("Ошибка запуска сервера:", err)
		os.Exit(1)
	}
	defer listener.Close()

	// Получаем реальный адрес и порт, который выделила система
	fmt.Printf("[SERVER] Запущен и ожидает подключений на %s\n", listener.Addr().String())

	for {
		conn, err := listener.Accept()
		if err != nil {
			fmt.Println("Ошибка подключения:", err)
			continue
		}

		go handleConnection(conn)
	}
}

func handleConnection(conn net.Conn) {
	defer conn.Close()

	buffer := make([]byte, 1024)
	n, err := conn.Read(buffer)
	if err != nil {
		return
	}

	fmt.Printf("[SERVER] Получено: %s\n", string(buffer[:n]))
	conn.Write([]byte("Привет от динамического сервера!"))
}
```

### 2. [[TCP]]-Клиент

Поскольку порт теперь каждый раз случайный, клиенту нужно передать точный адрес, который сервер вывел при старте.

Go

``` run-go
package main

import (
	"fmt"
	"net"
	"os"
)

func main() {
	// В реальной жизни этот адрес передается через конфиг, аргументы командной строки или Service Discovery.
	// Скопируйте сюда строку, которую выведет сервер (например, "127.0.0.1:54321")
	serverAddress := "127.0.0.1:60564" // <-- Подставьте актуальный порт из консоли сервера

	fmt.Printf("[CLIENT] Подключаемся к %s...\n", serverAddress)
	conn, err := net.Dial("tcp", serverAddress)
	if err != nil {
		fmt.Println("Не удалось подключиться:", err)
		os.Exit(1)
	}
	defer conn.Close()

	myAddress := conn.LocalAddr().String()
	message := fmt.Sprintf("Привет! Мой адрес: %s", myAddress)
	
	_, err = conn.Write([]byte(message))
	if err != nil {
		return
	}

	buffer := make([]byte, 1024)
	n, err := conn.Read(buffer)
	if err != nil {
		return
	}

	fmt.Printf("[CLIENT] Ответ от сервера: %s\n", string(buffer[:n]))
}
```

### Как это работает?

1. Когда вы вызываете `net.Listen("tcp", "127.0.0.1:0")`, сетевой стек операционной системы ищет в таблице портов любой неиспользуемый порт (обычно в диапазоне от 49152 до 65535) и закрепляет его за вашим приложением.
2. Метод `listener.Addr()` возвращает интерфейс `net.Addr`. Вызов `.String()` у него возвращает готовую строку вида `127.0.0.1:XXXXX`, которую чрезвычайно удобно логировать или передавать в другие сервисы.
