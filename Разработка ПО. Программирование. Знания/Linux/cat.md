## Работа с текстом и файлами

### `cat` (Concatenate)

Вывод содержимого файлов в терминал или их объединение.

- `cat file.txt` — вывести содержимое файла.
- `cat -n file.txt` — вывести строки с нумерацией (полезно для дебага кода).
- `cat file1.txt file2.txt > combined.txt` — объединить два файла в один.
## 🛠️ Главные флаги

- `cat -n file.txt` — вывести **все строки с нумерацией** (удобно для кода/логов).
- `cat -b file.txt` — нумеровать **только непустые** строки.
- `cat -s file.txt` — сжать несколько пустых строк подряд **в одну**.
- `cat -E file.txt` — показать **скрытые концы строк** (символ `$`).
- `cat -A file.txt` — показать **вообще все скрытые символы** (табы, переносы).

## 💡 Частые кейсы

- **Просмотр нескольких файлов подряд:**

cat file1.txt file2.txt

```
* **Создать файл и быстро записать текст из консоли:**
  ```bash
cat > new.txt
# Пиши текст. Для сохранения и выхода нажми Ctrl + D
```

- **Объединить файлы в один новый:**

cat part1.txt part2.txt > full.txt

```
* **Дописать один файл в конец другого:**
  ```bash
cat append.txt >> main.txt
```

## ⚠️ Антипаттерн: UUOC (Useless Use of cat)

- ❌ **Плохо:** `cat log.txt | grep "Error"` (лишний процесс)
- **Правильно:** `grep "Error" log.txt`

> **Совет:** Для огромных файлов вместо `cat` используй `less log.txt` (постраничный просмотр) или `tail -n 50 log.txt` (последние 50 строк).
