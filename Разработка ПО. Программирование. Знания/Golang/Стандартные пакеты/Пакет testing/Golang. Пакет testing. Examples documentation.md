# Golang. Пакет testing. Examples documentation

## Назначение

Examples documentation — возможность использовать Example-функции как **живую документацию**.

Главная идея:

> Пример использования API автоматически попадает в документацию и одновременно проверяется тестами.

---

## Пример

Код:

```go
func Add(a, b int) int {
	return a + b
}
```

Example:

```go
func ExampleAdd() {

	fmt.Println(Add(2, 3))

	// Output:
	// 5
}
```

Такой пример:

- выполняется при `go test`;
    
- отображается в документации.
    

---

## Где отображаются Examples

Examples можно увидеть:

- в `go doc`;
    
- на `pkg.go.dev`;
    
- в документации IDE (GoLand, VS Code и др.).
    

Пользователь библиотеки сразу видит готовый пример использования функции.

---

## Почему это удобно

Вместо описания:

```text
Функция Add складывает два числа.
```

можно показать рабочий код:

```go
result := Add(2, 3)

fmt.Println(result)

// Output:
// 5
```

Такой пример проще понять и он всегда проверяется тестами.

---

## Преимущества

- документация не устаревает;
    
- примеры всегда компилируются;
    
- примеры автоматически проверяются при `go test`;
    
- пользователи получают готовые рабочие примеры.
    

---

## Когда использовать

Examples особенно полезны для:

- библиотек;
    
- SDK;
    
- публичных API;
    
- пакетов с большим количеством функций.
    

Для внутренних проектов их используют реже.

---

## Для собеседования

> Example-функции могут служить документацией. Они отображаются в `go doc` и на `pkg.go.dev`, показывая пользователям готовые примеры использования API. Поскольку Examples запускаются как тесты, документация остаётся актуальной и не расходится с реальным кодом.
