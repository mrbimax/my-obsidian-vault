Посмотреть потоки (threads) конкретного процесса в Linux можно как в реальном времени (интерактивно), так и разовым снимком.

Вот 4 самых удобных способа, от графических утилит до работы с файловой системой `/proc`.

## Способ 1. Через `htop` (Самый наглядный)

`htop` идеально подходит для визуального анализа. По умолчанию он скрывает потоки, чтобы не захламлять экран, но это легко включить.

1. Запустите `htop`.
2. Нажмите **`F2`** (Setup) -> перейдите в раздел **Display options**.
3. Отметьте крестиком пункт **"Show custom thread names"** или убедитесь, что снята галочка с _"Hide kernel threads"_ / _"Hide userland process threads"_.
4. Вернитесь в главное меню (`Esc`).
5. Нажмите **`F5`**, чтобы включить дерево процессов.

**Результат:** Вы увидите главный процесс, а под ним — ветвление из его потоков (они обычно подсвечены зеленым цветом или имеют немного другое имя).

## Способ 2. Через `top` (Встроенный интерактивный)

Если `htop` не установлен, классический `top` тоже умеет переключаться в режим отображения потоков.

- **Вариант А (на лету):** Запустите `top`, как обычно, и прямо на экране нажмите комбинацию **`Shift + H`** (заглавная `H`). Вся таблица перестроится: вместо процессов она начнет показывать отдельные потоки.
    
- **Вариант Б (при запуске):** Запустите команду сразу с флагом `H` и указанием PID процесса:
    
    Bash
    
    ```Bash
    top -H -p <PID>
    ```
    
    _(Где вместо `<PID>` подставьте числовой идентификатор вашего процесса, например `top -H -p 1234`)_.
    

## Способ 3. Через `ps` (Для скриптов и быстрых снимков)

Если вам нужно получить список потоков один раз (например, чтобы передать его в текстовый файл), используйте `ps`.

- **Флаг `-m`** — показывает потоки после каждого процесса.
    
- **Флаг `-L`** — показывает потоки, добавляя колонку **LWP** (Light Weight Process — так в Linux называются потоки) и **NLWP** (общее количество потоков у процесса).
    

Самая удобная команда:

Bash

```Bash
ps -fL -p <PID>
```

**Пример вывода:**

Plaintext

```Bash
UID        PID  PPID   LWP  C NLWP STIME TTY          TIME CMD
root      1234  1100  1234  0    3 12:00 ?        00:00:05 my_go_app
root      1234  1100  1235  2    3 12:00 ?        00:00:42 my_go_app
root      1234  1100  1236  1    3 12:00 ?        00:00:15 my_go_app
```

_Обратите внимание: `PID` у всех строк одинаковый (1234), `NLWP` показывает, что всего потоков 3, а в колонке `LWP` видны уникальные ID каждого потока._

## Способ 4. Напрямую из ядра Linux (`/proc`)

В Linux всё есть файл. Информация обо всех потоках процесса хранится в директории `/proc/<PID>/task/`. Сколько папок внутри этой директории — столько потоков сейчас и запущено.

Чтобы просто **посчитать** количество потоков процесса:

Bash

```
ls /proc/<PID>/task/ | wc -l
```

Чтобы посмотреть подробный статус по каждому потоку (включая имя потока и его состояние):

Bash

```
cat /proc/<PID>/task/*/status | grep -E 'Name|Pid|Gid'
```

### Резюме: что выбрать?

- Нужно быстро починить/посмотреть глазами? Используйте **`top -H -p PID`** или настройте **`htop`**.
    
- Нужно зафиксировать логи или автоматизировать проверку? Используйте **`ps -fL -p PID`**.
    
- Нужно быстро узнать только _количество_ потоков, не нагружая систему? Проверьте папку **`/proc/PID/task/`**.
