# Шпаргалка: `chmod` (Change Mode)

**`chmod`** — утилита для изменения прав доступа (разрешений) к файлам и директориям. Она определяет, кто может читать файл, записывать в него данные или запускать на выполнение.

## 🔢 Как задаётся доступ цифрами?

Права доступа в Linux делятся на три независимые группы пользователей:

1. **Владелец** (`User` / `u`) — создатель файла.
2. **Группа** (`Group` / `g`) — пользователи, входящие в группу файла.
3. **Остальные** (`Others` / `o`) — все остальные пользователи в системе.

Для каждой группы права вычисляются сложением баллов базовых действий:

- **`4`** — чтение (**r**ead)
- **`2`** — запись (**w**rite)
- **`1`** — выполнение (**x**ecute)
- **`0`** — нет прав.

> ### 🧮 Пример вычисления:
> 
> Если тебе нужно дать группе прав следующие полномочия:
> 
> - Чтение (4) + Запись (2) + Выполнение (1) = **`7`**
> - Чтение (4) + Запись (2) = **`6`**
> - Чтение (4) + Выполнение (1) = **`5`**
> - Только чтение (4) = **`4`**
> 
> Итоговое число собирается из трех цифр: `[Владелец][Группа][Остальные]`.

## 🚀 Популярные комбинации в числовом формате

- `chmod 755 script.sh`
    
    - **7** (4+2+1): Владелец может всё (rwx).
    - **5** (4+1): Группа и Остальные могут только читать и запускать (r-x).
    - _Применение:_ Стандарт для исполняемых скриптов, бинарников и папок.
    
- `chmod 644 config.yaml`
    
    - **6** (4+2): Владелец может читать и править (rw-).
    - **4**: Группа и Остальные могут только читать (r--).
    - _Применение:_ Стандарт для обычных файлов, конфигов, исходного кода Go/Python.
    
- `chmod 600 id_rsa`
    
    - **6** (4+2): Владелец может читать и править (rw-).
    - **0**: У всех остальных доступа нет вообще (---).
    - _Применение:_ Обязательно для приватных SSH-ключей, токенов и файлов с паролями.

## 🔤 Альтернатива: Символьный формат

Иногда нужно не перезаписать права полностью цифрами, а просто точечно добавить или забрать одно право. Для этого используют буквы `u`, `g`, `o`, `a` (all — все) и знаки `+` / `-`.

- `chmod +x script.sh` — сделать файл исполняемым для **всех** (добавляет `x`).
- `chmod g-w config.toml` — **забрать** право на запись у группы.
- `chmod u+x,g-x deploy.sh` — владельцу добавить выполнение, у группы убрать.

## 🛠️ Полезный флаг

- **`-R` (Recursive):** Применяет права рекурсивно ко всей директории и её содержимому.
    Bash
    ```Bash
    chmod -R 755 /var/www/my-app/
    ```
