# Шпаргалка: `cd` (Change Directory)

**`cd`** — встроенная команда командной оболочки (bash/sh/zsh) для изменения текущей рабочей директории (навигации по файловой системе).

## 🚀 Основные команды навигации

- `cd /absolute/path/to/dir` — переход по **абсолютному пути** (от корня системы `/`).
- `cd ./relative/path` — переход по **относительному пути** (от текущей папки). Символ `.` означает текущую директорию.
- `cd ..` — подняться на **один уровень вверх** (в родительскую папку).
- `cd ../..` — подняться на **два уровня вверх**.

## ⚡ Быстрые переходы (Шорткаты)

- `cd` или `cd ~` — мгновенный переход в **домашнюю директорию** текущего пользователя (например, в `/home/magnum_opus`).
- `cd -` — вернуться в **предыдущую рабочую директорию**.
    
    > 💡 **Зачем это нужно:** Удобно прыгать туда-обратно между двумя глубоко вложенными папками (например, между конфигурациями `/etc/nginx/sites-available/` и логами `/var/log/nginx/`). Повторный вызов `cd -` вернет тебя обратно.
    

## 🛠️ Полезные фичи и трюки в CLI

- **Автодополнение (Tab):** Начни писать имя папки и нажми `Tab`. Если вариантов несколько, нажми `Tab` дважды для вывода списка.
	- **Работа с пробелами в именах папок:** Если в названии директории есть пробелы, его нужно либо обернуть в кавычки, либо экранировать пробел обратным слэшем:
    Bash
    ```Bash
    cd "my projects"
    # или
    cd my\ projects
    ```
