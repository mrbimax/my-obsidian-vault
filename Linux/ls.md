# Шпаргалка: `ls` (List)

**`ls`** — утилита для просмотра содержимого директорий (выводит список файлов и папок).

## 🛠️ Главные флаги (Опции)

|Флаг|Что делает|Зачем нужен|
|---|---|---|
|`-l`|Длинный формат (Long)|Показывает права доступа, владельца, размер и дату изменения.|
|`-a`|Все файлы (All)|Отображает скрытые файлы и папки (те, что начинаются с точки, например `.env`, `.git`).|
|`-h`|Человекочитаемый (Human)|Переводит размер файлов из байт в понятные `K` (Кб), `M` (Мб), `G` (Гб). Работает только в связке с `-l`.|
|`-t`|Сортировка по времени|Первыми выводит самые свежие (недавно измененные) файлы.|
|`-r`|Реверс (Reverse)|Разворачивает порядок вывода (например, от старых к новым при `-tr`).|
|`-R`|Рекурсивно|Выводит содержимое текущей папки и всех её подпапок (вложенных директорий).|

## 🚀 Популярные комбинации

- **Классическое комбо бэкендера:**
    Bash

    ```Bash
    ls -lah
    ```
    Выводит абсолютно все файлы (включая скрытые конфигурации вроде `.dockerignore`), со всей метаинформацией и в удобном для чтения формате размера.
- **Найти последние измененные файлы (удобно искать свежие логи):**
    Bash
    ```Bash
    ls -lt
    ```
- **Вывести список, где сначала идут самые старые файлы, а в самом низу терминала — самые новые:**
    Bash
    ```Bash
    ls -ltr
    ```

## 🔍 Разбор вывода `ls -l`

Когда ты вводишь `ls -l`, каждая строка выглядит примерно так:

Plaintext

```Bash
-rw-r--r--  1 root  root  4.0K May 25 14:30 main.go
```

1. **`-rw-r--r--`** — Тип элемента и права доступа. Первый символ `-` означает файл (`d` — директория, `l` — ссылка). Далее идут три тройки прав (rwx) для владельца, группы и остальных.
2. **`1`** — Количество жестких ссылок на файл.
3. **`root` (первый)** — Имя пользователя-владельца файла.
4. **`root` (второй)** — Имя группы-владельца файла.
5. **`4.0K`** — Размер файла (благодаря флагу `-h`).
6. **`May 25 14:30`** — Дата и время последней модификации.
7. **`main.go`** — Имя файла/папки.
