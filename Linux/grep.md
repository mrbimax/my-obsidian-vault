# Шпаргалка: `grep` (Global Regular Expression Print)

**`grep`** — мощнейшая утилита для поиска строк, соответствующих заданному шаблону (включая регулярные выражения), в файлах или потоках данных (`stdin`).

## 🛠️ Главные флаги (Опции)

|Флаг|Что делает|Зачем нужен|
|---|---|---|
|`-i`|Игнорирует регистр букв|Найти и `ERROR`, и `error`, и `Error`|
|`-v`|**Инвертирует** поиск|Вывести всё, где **нет** указанного слова (отсечь флуд)|
|`-r` / `-R`|Рекурсивный поиск|Искать строку во всех файлах в папке и её подпапках|
|`-n`|Выводит номера строк|Сразу видно, на какой строке исходного файла нашлось совпадение|
|`-c`|Выводит только **количество** строк|Быстро посчитать число ошибок/запросов в логе|
|`-E`|Включает расширенные регулярки (ERE)|Чтобы использовать символы `|

## 💡 Точечный вывод контекста (Важно для дебага логов)

Часто бэкендеру важно увидеть не только саму строку с ошибкой, но и то, что происходило _до_ или _после_ неё (например, стек-трейс паники).

- `grep -A 5 "panic" app.log` — (**A**fter) вывести строку с совпадением + **5 строк после** неё.
- `grep -B 3 "ERROR" app.log` — (**B**efore) вывести строку с совпадением + **3 строки до** неё.
- `grep -C 2 "failed" app.log` — (**C**ontext) вывести по **2 строки до и после** совпадения.

## 🚀 Частые кейсы использования

### 1. Поиск в файлах

- **Найти конфигурационный параметр в папке:**
    Bash
    ```Bash
    grep -rn "max_connections" /etc/nginx/
    ```
- Использование регулярных выражений (например, найти строки, начинающиеся со слова `func` в Go-файлах):
    Bash
    ```Bash
    grep "^func" main.go
    ```

### 2. Поиск в пайплайнах (Комбинация с другими утилитами)

- **Фильтрация вывода процессов:**
    Bash
    ```Bash
    ps aux | grep "etcd"
    ```
    
- **Поиск конкретной ошибки в реальном времени через journalctl:**
    Bash
    ```Bash
    journalctl -u my-service.service -f | grep --line-buffered "500 Internal Server Error"
    ```
    _(Флаг `--line-buffered` заставляет grep отдавать строки сразу, не задерживая их в буфере)._

## ⚠️ Антипаттерн: UUOC (Useless Use of cat)

- ❌ **Неэффективно:** `cat settings.json | grep "port"`
- **Правильно:** `grep "port" settings.json`
