# Шпаргалка: `vim`

**Vim** — модальный текстовый редактор. Чтобы начать писать, нужно войти в режим вставки, а чтобы управлять текстом — вернуться в командный режим.

## 🕹️ Главные режимы (Переключение)

- `i` — **Режим вставки (Insert):** обычный ввод текста.
- `Esc` — **Командный режим (Normal):** перемещение, удаление, копирование (активен по умолчанию).
- `:` — **Режим командной строки:** выполнение команд (сохранение, выход, поиск).
## 💾 Сохранение и Выход (В командной строке `:`)

- `:w` — сохранить изменения.
- `:q` — выйти (работает, если нет несохраненных изменений).
- `:q!` — выйти **без сохранения** изменений.
- `:wq` или `:x` — сохранить и выйти.

## 🚀 Быстрое редактирование (В Normal режиме)

- `u` — отменить последнее действие (Undo).
- `Ctrl + r` — вернуть отмененное действие (Redo).
- `dd` — **вырезать/удалить** текущую строку.
- `yy` — **скопировать** текущую строку.
- `p` — **вставить** скопированную/вырезанную строку ниже.
- `x` — удалить один символ под курсором.

## 🔍 Перемещение и Поиск

- `GG` — прыгнуть в самый **конец** файла.
- `gg` — прыгнуть в самое **начало** файла.
- `/слово` — поиск слова по файлу (`n` — следующее совпадение, `N` — предыдущее).
- `:%s/старое/новое/g` — заменить _старое_ на _новое_ по всему файлу.
