# this is rare
?
# Meaning:
- Used to say that something is unusual, uncommon, or surprising.
- Often used ironically to mean that something is actually very typical or predictable.
# Usage:
- Informal everyday phrase. Can be sincere, but sarcastic use is very common when someone points out something that happens all the time.
# Example:
- _He remembered my birthday? This is rare._
- _You're complaining about the traffic? This is rare—you say that every day._
# Russian:
- Это редкость. / Это бывает редко.
- Саркастически: Ну надо же, такое бывает! / Подумать только, вот это новость! (когда на самом деле это обычное дело).
- Буквально: «это редко».
