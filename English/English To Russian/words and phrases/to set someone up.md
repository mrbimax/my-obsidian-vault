# to set someone up
?
# Transcription:
- /tə set ˈsʌmwʌn ʌp/
# Meaning:
- To arrange for someone to be in a particular situation, especially to help them or give them an opportunity.
- To trick or frame someone so they appear guilty or are put in a difficult position.
- To arrange a meeting or date between two people; to set someone up with someone.
# Usage:
- Common patterns: set someone up in business, set someone up with a friend, set someone up for a fall, set someone up to take the blame.
- Neutral to informal. The "frame" sense is negative and common in crime and conflict contexts.
# Example:
- _Her parents set her up in a small apartment near the university._
- _He claimed the police had set him up._
- _My sister set me up with her colleague._
