# spent-uranium
?
# Transcription:
- /spent jʊˈreɪniəm/
# Meaning:
- Uranium that has been used as fuel in a nuclear reactor and is no longer efficient for continued use.
- It is highly radioactive and requires careful handling, storage, and disposal.
# Usage:
- Technical and nuclear industry term. Usually written without a hyphen as "spent uranium". Not the same as depleted uranium.
# Example:
- _Spent uranium is stored in cooling pools before disposal._
- _The plant has strict procedures for managing spent uranium._
# Russian:
- Отработанный уран; отработавшее ядерное топливо (в широком смысле).
- Не путать с _depleted uranium_ — обеднённый уран. _Spent uranium_ — уран, уже использованный в реакторе.
